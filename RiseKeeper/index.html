Layered protection

Built around how alarms get bypassed.

The system always provides its own Stop control. RiseKeeper is transparent about that — and adds multiple layers after the tap.

Layer 01

Strict Mode

Detects a bypass and can schedule a short re-alert, while each mission input keeps the protection countdown fresh.

Layer 02

Wake-Up Check

Pro can check back a few minutes later and ask for another mission, helping prove you actually stayed up.

Layer 03

Protected snooze

A snoozed mission alarm cannot be switched off inside RiseKeeper before the mission is completed.

Layer 04

One active wake session

Related recovery alarms pause while a mission is active, so the same wake session does not ring over itself.

Q01Does RiseKeeper need to stay open for an alarm to ring?System alarm+

No. RiseKeeper schedules a system alarm, so the app does not need to remain open. Your iPhone still needs power, alarm permission, and compatible system settings.

Q02Will my custom sound still ring after I close the app?Custom audio+

Yes. Compatible custom audio is converted and stored locally where the scheduled system alarm can use it. Recording inside RiseKeeper and Music Library selection require Pro; importing compatible Files or Voice Memos audio is free.

Q03Can the system Stop button bypass a mission?System Stop+

The system always provides a Stop control. RiseKeeper does not claim otherwise. Strict Mode can detect a bypass and re-alert, while protected snooze and Wake-Up Check add more follow-through.

Q04Can I try premium missions before purchasing?Preview mode+

Yes. Typing, Memory, and Odd One Out can all be played in preview mode before you unlock Pro.

Q05Is RiseKeeper Pro a subscription?Purchase+

No. RiseKeeper Pro is a one-time, non-consumable purchase for lifetime access. Restore Purchases is available in Settings → RiseKeeper Pro.

Q06My alarms do not appear. What should I check?Troubleshooting+

Open Settings on iPhone and make sure alarm access is enabled for RiseKeeper. Then open RiseKeeper once so it can reconcile saved alarms with the system. If the issue continues, contact support.
