Jarvis

open source

A self-improving CLI coding agent that runs inside its own repository and ships its own features. A cron-driven worker picks the next roadmap item, implements it, writes tests, opens a PR, and squash-merges when CI passes.

PythonAzure OpenAIMCPGitHub Actions
How it works
  • Streaming tool-use loop: read, edit, run, search, web.
  • Unified-diff permission gate before any write touches disk.
  • Plan mode and auto mode, with session logging and per-session cost tracking.
  • Model Context Protocol integrations and auto-compacting context.
  • CI across Python 3.11 to 3.13, plus SSH deploy of every green build back to the VM improving it.

Ricochet Requiem

open source

An arena action roguelite where your shots only hurt after they bounce. Every room becomes a geometry puzzle you solve at speed while being chased, which makes walls into ammunition.

Godot 4GDScript
Design constraints I set
  • The core verb has to be fun in an empty gray room, or it gets cut.
  • The player causes every kill. No auto-fire, no companion, no idle damage.
  • Systems can be deep, but the first ten seconds must be legible.
  • Death to back in action in under two seconds. Never punish with boredom.
